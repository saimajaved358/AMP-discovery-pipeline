# 🧬 AMP Discovery Pipeline

A reproducible bioinformatics workflow for identifying antimicrobial peptides (AMPs) from bacterial genomes using genome annotation, peptide prediction, and downstream functional analyses.

---

# 📖 Overview

This repository contains my bioinformatics pipeline developed for antimicrobial peptide (AMP) discovery from bacterial genomes.

The workflow integrates genome annotation, protein extraction, AMP prediction, similarity searches, and functional annotation into a reproducible analysis pipeline.

This repository is part of my research in:

- Antimicrobial Resistance (AMR)
- Microbial Genomics
- Metagenomics
- Comparative Genomics
- One Health

---

# 🔬 Pipeline Workflow

The pipeline consists of the following major steps:

1. Genome assembly (optional)
2. Genome quality assessment
3. Genome annotation
4. Protein sequence extraction
5. AMP prediction
6. Similarity search
7. Functional annotation
8. Result summarization
