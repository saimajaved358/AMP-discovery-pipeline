# AMP Discovery Workflow

This directory contains the complete workflow for antimicrobial peptide (AMP) discovery from bacterial genomes.

## Workflow Steps

1. Genome annotation using Bakta
2. Protein sequence extraction
3. Small peptide filtering
4. AMP prediction using AMPEP
5. AMP prediction using Macrel
6. Similarity search against AMPSphere
7. Functional annotation
8. Final candidate peptide selection

The complete workflow diagram is available as `AMP_workflow.png`.
